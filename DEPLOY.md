# Как выложить сайт в интернет — пошаговая инструкция для новичков

Хорошая новость: отдельный «сервер» покупать не нужно. GitHub Pages бесплатно хостит такие сайты — просто нужно создать репозиторий на GitHub и один раз включить публикацию. Дальше сайт будет обновляться сам при каждом сохранении изменений.

Всё, что нужно, у вас уже есть: Node.js установлен, Git установлен, проект собирается. Осталось только сделать эти шаги.

## Шаг 1. Создать аккаунт на GitHub (если ещё нет)

1. Откройте [github.com/signup](https://github.com/signup)
2. Придумайте имя пользователя, укажите почту и пароль
3. Подтвердите почту по ссылке, которую пришлют на неё

Если аккаунт уже есть — пропустите этот шаг.

## Шаг 2. Создать пустой репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) под своим аккаунтом
2. Нажмите **+** в правом верхнем углу → **New repository**
3. **Repository name**: впишите `srb-pdd-trener` (важно именно так — этот путь уже прописан в настройках проекта; если хотите другое имя — см. раздел «Если назвали репозиторий иначе» ниже)
4. Выберите **Public** (для бесплатного GitHub Pages репозиторий должен быть публичным)
5. **Не ставьте** галочку «Add a README file» — у нас уже есть готовый проект с файлами
6. Нажмите **Create repository**
7. GitHub откроет страницу с инструкциями — на ней будет адрес вида `https://github.com/ВАШ_ЛОГИН/srb-pdd-trener.git`, он понадобится в следующем шаге

## Шаг 3. Отправить проект на GitHub

Откройте терминал в папке проекта (тот же, где вы работали со мной) и выполните команды по очереди. Замените `ВАШ_ЛОГИН` на свой логин на GitHub.

```bash
git add .
```

```bash
git commit -m "Первая версия тренажёра"
```

```bash
git branch -M main
```

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/srb-pdd-trener.git
```

```bash
git push -u origin main
```

На последней команде GitHub спросит логин и пароль. **Обычный пароль от аккаунта не подойдёт** — вместо него нужен специальный токен:

1. На GitHub: аватар (справа вверху) → **Settings** → в самом низу левого меню **Developer settings**
2. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
3. Поставьте галочку **repo** (даёт доступ к репозиториям), внизу — **Generate token**
4. Скопируйте показанный токен (он больше не покажется — если потеряете, придётся создать новый)
5. При запросе пароля в терминале вставьте этот токен вместо пароля

## Шаг 4. Включить публикацию сайта (GitHub Pages)

1. На странице репозитория откройте **Settings** → в левом меню **Pages**
2. В разделе «Build and deployment» → **Source** выберите **GitHub Actions**

Больше ничего настраивать не нужно — скрипт публикации (`.github/workflows/deploy.yml`) уже лежит в проекте и запустится сам при каждом `git push` в ветку `main`.

## Шаг 5. Добавить ключи Supabase (если уже создали Supabase-проект)

Если вы ещё не создавали Supabase-проект — пропустите этот шаг, сайт всё равно опубликуется, просто раздел «Профиль» не будет сохранять прогресс между сессиями, пока вы это не настроите.

1. **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
2. Имя: `VITE_SUPABASE_URL`, значение — Project URL из настроек вашего Supabase-проекта (Project Settings → API)
3. Ещё раз **New repository secret** → имя `VITE_SUPABASE_ANON_KEY`, значение — anon public key оттуда же

## Шаг 6. Проверить, что всё сработало

1. Откройте вкладку **Actions** на странице репозитория
2. Появится запуск — сначала жёлтый кружок (идёт сборка), затем зелёная галочка (готово), обычно занимает 1–2 минуты
3. После зелёной галочки откройте сайт по адресу:
   `https://ВАШ_ЛОГИН.github.io/srb-pdd-trener/`

## Если назвали репозиторий иначе, не `srb-pdd-trener`

Откройте файл `vite.config.ts`, найдите строку:

```
base: '/srb-pdd-trener/',
```

и замените `srb-pdd-trener` на имя вашего репозитория, сохраните файл, затем:

```bash
git add vite.config.ts
```

```bash
git commit -m "Поправил base path под имя репозитория"
```

```bash
git push
```

## Как обновлять сайт дальше

Каждый раз, когда контент или код меняются (например, если я что-то доработаю), нужно просто повторить:

```bash
git add .
```

```bash
git commit -m "описание того, что изменилось"
```

```bash
git push
```

GitHub Actions сам пересоберёт сайт и обновит его по тому же адресу — обычно за 1–2 минуты.
